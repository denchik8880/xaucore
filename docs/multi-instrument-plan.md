# Новые инструменты: EURUSD, Boom 1000, Crash 1000

Запрос пользователя от 16.11.2026: «создадим EURUSD и какой-то индекс, который будет через генератор как в Deriv работать».

Что выбрал пользователь:
- **Синтетика:** Boom 1000 и Crash 1000.
- **Счёт:** один общий на все инструменты.

Уточнения пользователя:
- «бум и краш должны быть с такой логикой как и у дерив»;
- EURUSD «по котировкам похожие на реальные, но не реальные»;
- «не нужно задавать диапазон, оно само должно двигаться как настоящее»;
- «как лоты и маржа там считаются — посмотри у FxPro».

## Как устроено сейчас

Приложение рассчитано на один XAUUSD:
- `S.symbol` — спецификация инструмента.
- `S.price` — цена, 210 обращений.
- `S.candles` — свечи.
- `S.market`, `S.regime`, `S.news`, `S.fed`, `S.day` — сложный движок золота.
- `S.hist` и `/api/hist` — история графика.

У позиций и ордеров нет поля «инструмент».

## Подход

Движок золота не трогаем: он продолжает писать `S.price` и `S.candles`. Это инструмент XAUUSD.

Новые инструменты — отдельный модуль в `public/index.html`, между маркерами `/* ======== OTHER INSTRUMENTS` и `END OTHER INSTRUMENTS` (сразу после `updateCandles()`).

Состояние каждого инструмента: `{ sym, seed, t, gold, gv, spikes, price, candles }`.
- `price` — `{bid, ask, mid, spread, prevMid, lastVol, spiked?}`.
- `candles` — тот же формат, что у золота: `{TF: [{t, o, h, l, c, v}]}`.
- Лимиты `INS_CAP`: M1 400, M5 300, M15 200, M30 200, H1 200, H4 150, D1 120.

**Свой генератор случайных чисел.** Инструменты берут случайные числа из своего `st.seed` (mulberry32), а не из `Math.random`. Поэтому золото получает ровно те же случайные числа, что и раньше, и движется так же. Тест запрещает модулю `Math.random`.

**Время — игровое.** Инструменты догоняют `S.simClock` после тиков золота (`insAdvance(box, nowMs, {mid, news, closed})`):
- тики Boom/Crash идут раз в **игровую** секунду, как и весь ускоренный день;
- длинный скачок часов заполняется поминутно;
- после отсутствия больше 3 дней история строится заново от текущей цены;
- `insShift(box, ms)` двигает время вместе с `shiftSimTime`.

**История.** Один путь идёт назад от текущей цены: минутными шагами 200 часов, дальше 15-минутными. Этот путь режется сразу на все таймфреймы, поэтому таймфреймы согласованы между собой. Три истории строятся примерно за 47 мс на ПК.

### EURUSD — как на cTrader у FxPro

Данные с fxpro.com, прочитаны 16.11.2026.

| Параметр | Значение |
|---|---|
| Старт | 1.1005 — реальная котировка дня. Дальше цена ходит сама: без диапазона и без притяжения |
| Цифр / пункт | 5 / 0.0001 |
| Контракт | 100 000 EUR (0.01 лота = 1000 EUR), шаг 0.01 |
| Комиссия | $0.35 за 10K оборота за сторону (1 лот ≈ €3.50 ≈ $3.85 на вход и столько же на выход) |
| Свопы | −8.9 / +1.9 пункта на лот за ночь (1 пункт на лоте = $1), тройной в среду |
| Спред | в среднем ~0.46 пункта (raw); шире в ролловер (×3), в тонкие часы и на новостях (×4) |
| Дневной диапазон | 60–100 пунктов; в модели дневная волатильность 0.48 %, получается ~85 пунктов |
| Часы | как у золота: торгуется, пока рынок открыт |

**Маржа.** Маржа в долларах = лоты × 100 000 × цена / плечо.

Плечо — это плечо счёта, но не выше ступени динамического плеча FxPro для открытого объёма по инструменту. Каждая часть объёма считается по своей ступени. Ступени FX majors:

| Объём, лотов | Плечо |
|---|---|
| ≤1 | «без лимита», то есть плечо счёта |
| ≤10 | 1:10000 |
| ≤25 | 1:2000 |
| ≤50 | 1:1000 |
| ≤100 | 1:888 |
| ≤200 | 1:500 |
| ≤300 | 1:200 |
| ≤400 | 1:100 |
| больше | 1:50 |

У золота в FxPro тоже есть такие ступени: ≤1 лота без лимита, дальше 1:10000 … 1:50 на 50+ лотах. **У нас золото пока на фиксированном плече счёта: менять его только с согласия пользователя.**

**Связь с золотом через доллар.** Шаг EURUSD опирается на шаг золота: корреляция доходностей около +0.42 в обычное время и около +0.7 на новостях. На новостях своя волатильность ×1.5.

**Часовой профиль FX:** Токио тихий, Лондон и пересечение Лондона с Нью-Йорком самые активные.

### Boom 1000 и Crash 1000 — как у Deriv

| Параметр | Значение |
|---|---|
| Тик | раз в игровую секунду, 24/7, без новостей |
| Всплеск | вероятность 1/1000 на каждом тике. Boom вверх, Crash вниз; размер 3 + экспонента со средним 12 |
| Между всплесками | дрейф в обратную сторону 0.015 за тик, шум 0.012. Около 9 тиков из 10 идут по дрейфу, 95 % минутных свечей одного цвета («лесенка») |
| Баланс | дрейф в среднем возвращает всплески: индекс бродит, но не убегает |
| Цифр | 4 (как на скриншоте cTrader пользователя: 14885.3322) |
| Контракт | 1 лот = $1 за пункт |
| Лот | мин. 0.20, шаг 0.01, не больше 250 лотов открыто по индексу |
| Плечо | плечо счёта, но не больше 1:600 |
| Свопы | −36 % годовых на объём в обе стороны (таблица Deriv) |
| Комиссия | нет |
| Спред | доля цены, как у Deriv: 0.0115 % (~1.72 при 14 886; на скриншоте S 17185) |
| Старт | Boom 14 886 (скриншот пользователя), Crash 6 800 (реальную цену ещё уточнить) |

Margin = лоты × цена / плечо.

### Активный инструмент

- `S.ui.sym`, по умолчанию `"XAUUSD"`.
- Интерфейс читает данные через помощники вида `P(sym)`, `SPEC(sym)`, `CNDL(sym)`. Касается это:
  - строки списка инструментов;
  - страницы инструмента;
  - графика;
  - тикета;
  - панели «Продать/Купить».
- Движок золота продолжает писать прямо в `S.price`.

### Позиции и ордера

- У каждой позиции и ордера появляется поле `sym`. Старые получают `"XAUUSD"`.
- Прибыль, маржа, SL/TP, исполнение отложенных ордеров, комиссия и своп считаются по цене и спецификации своего инструмента. Готовые функции: `insMargin`, `insCommission`, `insSwap`.

### Счёт

Один баланс, одна маржа. `recalcAccount` суммирует все позиции.

## Сделано и выложено (17.11.2026)

Пользователь: «можете уже добавить EURUSD и BOOM1000, краш не нужен».

**Инструменты.** На сайте XAUUSD, EURUSD и BOOM1000. Crash 1000 убран из спецификаций, генераторов и тестов.

**Движок:**
- Помощники `quoteOf` / `specOf` / `marginFor` / `symOf`.
- Всё, что считает счёт, берёт котировку и условия инструмента позиции или ордера: P/L, комиссия, маржа (EURUSD по ступеням FxPro, Boom до 1:600), лимит объёма Boom 250, SL/TP, отложенные ордера, свопы, стоп-аут.
- Boom торгуется и при закрытом рынке золота.

**Часы.** Инструменты двигаются после каждого шага золота (`insTick` в `updateCandles`) и сдвигаются вместе с днями (`insShift`).

**Сохранение.** `S.ins` уходит в `stateJSON` через кэш баров (`insJSON`). Живой кадр для второго устройства несёт их котировки и хвосты свечей.

**Интерфейс:**
- Список «Рынки» — три строки в дизайне cTrader 2026-11:
  - спред и изменение EURUSD в пипсах с десятой;
  - цена Boom сжимается под кнопку.
- Экран инструмента показывает инструмент `S.ui.sym` (`curSym`, `VQ` / `VS`, `vpx` / `vcx`): обзор, мини-график, график, тикет, панель «Продать/Купить», стакан, карточка нижней панели.
- Лот подгоняется под границы инструмента (`setSym`, `quickLots`).
- Позиции, ордера и история показываются с разрядностью своего инструмента.
- Вкладки «Позиции» и «Ордера» на экране инструмента показывают только его.

**Тесты.** `tests/trading-instruments.test.mjs` (7 тестов).
